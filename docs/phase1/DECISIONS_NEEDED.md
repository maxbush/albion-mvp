> Правило для агентов: **бизнес-правила не придумываются в коде.** Если значения
> нет в этой таблице (или оно помечено ❓), агент реализует настройку с
> дефолтом из колонки «Дефолт» и пишет вопрос в описании PR.
>
> Статусы: ✅ подтверждено владельцем · 🟡 дефолт, ждём подтверждения клиента · ❓ открыто.
> Решения с пометкой «PR #9» взяты из раздела «Решения владельца» в PR #9.
